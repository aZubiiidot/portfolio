PROJECT DESCRIPTION
  • Role: 3D Generalist | Ionart Studios
  • Core Stack: Houdini (Solaris/Karma), Camera Tracking / Rendering / Matchmove Tools, Utility AOVs
  • Main Focus: Camera Tracking, Production Set Extensions & Replacements, Technical Render Layer Setup

This project was a feature-length biographical historical drama film.
My role focused on executing core production tasks for a handful of shots that required seamless, realistic background modifications. The work primarily consisted of solid camera tracking, aligning 3D elements perfectly to the live-action plates, and performing essential set extensions or object replacements.
The main goal was delivering rock-solid technical foundations and optimized render layers to ensure the compositing team could achieve the highest possible final image quality without technical bottlenecks.

MY TASKS
  • Camera Tracking, Plate Alignment: I performed precise camera tracking and matchmove operations for the assigned shots.
    I ensured that all virtual cameras and 3D elements locked perfectly to the live-action footage, eliminating any sliding or alignment errors before the assets went to rendering.
  • Set Extensions and Element Replacement: I assisted in clean-up and environment modification tasks, placing digital environment extensions and replacing specific background elements within the scenes according to the project's historical requirements.
  • Technical Render Layers and AOVs: I set up the shading, basic lighting, and rendering for the 3D elements inside Solaris/Karma.
    My focus was on breaking down the scenes into clean, optimized utility layers and custom AOVs to give the compositing artists maximum control over the final integration.
